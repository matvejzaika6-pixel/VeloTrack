# 🚴 VeloTrack

Минималистичное PWA-приложение для записи велосипедных поездок.
Работает офлайн, без серверов и аккаунтов.

## Возможности

- GPS-трекинг маршрута в реальном времени
- Карта на базе OpenStreetMap (Leaflet)
- Статистика: скорость, дистанция, время, калории
- Построение маршрута (OSRM + Nominatim, требует интернет)
- Экспорт и импорт поездок в .json
- История поездок
- Полностью офлайн — данные хранятся локально

## Использование

1. Скачай `index.html` и `manifest.json`
2. Открой `index.html` в браузере
3. На мобильном: «Добавить на главный экран» → работает как приложение

## Технологии

- Leaflet 1.9 + OpenStreetMap
- OSRM (велосипедная маршрутизация)
- Nominatim (геокодинг)
- localStorage (хранение данных)
- Чистый HTML/CSS/JS, без фреймворков
